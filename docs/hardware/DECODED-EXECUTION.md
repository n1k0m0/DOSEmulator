C13 additionally admits prefix-free `80/81/83` ALU/CMP operations with an immediate and a current ordinary-RAM operand. `83` sign-extends its byte; `80/81` retain their encoded widths. The complete displacement and immediate remain covered by the byte guard. Actual ModRM/SIB/displacement/immediate fetch touches precede the data read and optional write, including shared TLB slots. The interpreter can reuse immutable instruction encodings for a bounded run of ordinary register, RAM and stack instructions. Each executed instruction retains the existing four nominal clocks. The PC owner checks actual interrupts and resets first, then limits execution to the next scheduler or caller deadline. A callback at the final boundary sees the final instruction and the same complete scheduler conversion state as scalar execution.

The cache is derived host data in a weak association with a CPU. It contains encoding plans and copied source bytes, with at most 4096 entries and 64 instructions per entry. It contains no live CPU reference, RAM span, data address or translation. It is not part of the saved machine state. Every lookup checks the complete code context and all retained instruction bytes. Restoring a machine, modifying code, changing mappings or reusing a physical address never authorizes execution through an old plan by itself.

Admission requires a current permitted code translation and a complete plain RAM page. Live registers, segments, alignment, paging rights, dirty state and RAM mappings are checked for every data or stack access. Stores overlapping the entire physical code page, including aliases through paging or A20, fall back to the scalar interpreter. A failed admission does not fill a TLB entry, set page-table bits, read MMIO or change CPU state.

The admitted stack subset is prefix-free register PUSH/POP, PUSHA/POPA and direct near CALL/RET. Operand size and SS.B remain independent. PUSH stores the original SP/ESP value; POP commits the stack advance before writing its destination register. PUSHA preserves the original raw register value and its eight original preflight accesses. POPA really reads the discarded SP slot. RET checks the bytes it reads and its return target; its argument adjustment does not invent an additional memory access. Wraps, page crossings, cold or unsuitable translations, device mappings and faulting targets use the original interpreter.

Single stepping, instruction/interrupt observers, active debug conditions, interrupt shadows, pending REP state and numeric-error waits retain conservative execution. Unsupported encodings retain the scalar decoder. Code/data TLB hit counts and replacement ages, instruction checkpoints, flags and retirement counters remain part of full-state comparisons; they are not excluded as performance diagnostics.

The explicit ordinary execution overload remains available for comparison. A faster private workload is not proof of realtime Windows, historical cycle calibration, native graphics/audio behavior or compatibility of an older snapshot build. Snapshot format 1 keeps its existing strict five-module identity.
